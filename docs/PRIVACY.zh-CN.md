# 公开与私有资料

[English](PRIVACY.md)

| 位置 | 适合存放的内容 |
|---|---|
| 公开仓库 | 通用脚本和教程、机型/BIOS参考、隐私化示例及截图 |
| 用户自建私有仓库 | 原始日志/截图、本机配置、硬件映射、连接信息及审核记录 |
| 离线U盘 / 受控NAS | ESP、固件变量、配置备份及完整恢复U盘包 |

私钥、密码、令牌和恢复密钥不能进入**任何Git仓库**。IP/MAC、账号、序列号、设备/分区标识和个人路径留在私有位置。核验所需的通用固件GUID和发行版哈希可以公开。

发布前，用户和AI agent都必须：

1. 使用占位符和可复用说明。对话经过、个人检查台账、截图数量、耗时及审核回执留在私有仓库。
2. 检查截图像素和元数据，扫描文本中的标识和凭据；自动检查不能替代人工看图。
3. 审核暂存文件、差异及全部待推送提交。仅删除最新版文件，不会清除旧提交中的内容。

```sh
python3 -B scripts/privacy_check.py .
# 可选私有JSON：敏感字符串列表、图片相对路径到SHA256的映射。
python3 -B scripts/privacy_check.py . \
  --denylist "$PRIVATE_DENYLIST" --image-allowlist "$PRIVATE_IMAGE_ALLOWLIST"
```

扫描通过不等于可以直接发布。大型恢复镜像不入Git；含私有配置的归档应限制访问。
